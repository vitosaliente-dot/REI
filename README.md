# REI

Script para buscar odds de valor comparando BetMGM e Bet365 utilizando [The Odds API](https://the-odds-api.com/).

## Uso

1. Defina a variável de ambiente `ODDS_API_KEY` com sua chave do serviço.
2. Execute o script:

```bash
python value_bet.py
```

O script retornará a melhor odd de valor encontrada entre as duas casas.
